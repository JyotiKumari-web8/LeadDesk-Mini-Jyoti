Why it changed to Dark Blue

The previous stylesheet included a @media (prefers-color-scheme: dark) media query. If your browser or operating system had dark mode enabled, the app automatically switched from the light theme to a dark navy / midnight blue background (#0b0f19 and #131b2e).

---

What Has Been Fixed

1. Removed the Dark Mode Override: Removed the automatic dark color scheme override so the app remains in the bright, light theme regardless of system settings.
2. Restored & Enhanced White & Light Blue Palette:
- Main Background: Soft light blue tinted white (#f0f7ff)
- Cards & Surfaces: Clean pure white (#ffffff) with subtle light blue borders (#dbeafe)

---

1. What This Project Can Do

LeadDesk-Mini is a full-stack Lead Management & CRM System with two sides:

1. Public Landing & Contact Page (/):
- Visitors can submit inquiries with their Name, Email, Phone, Company, Estimated Budget, and Message.
- Live validation prevents submission errors.
2. Protected Admin Workspace (/admin):
- Interactive Kanban Board: Drag & drop or update lead stages (New, Contacted, Qualified, Lost).
- Data Table View: Search, filter by status/priority, and sort leads.
- Lead Details Modal: View prospect details, edit info, and write time-stamped internal team notes.
- Metrics & Analytics: Instant counts for total leads, qualified prospects, and conversion pipeline.
- CSV Export: Download lead lists into spreadsheets with one click.

---

2. Step-by-Step Guide: How to Use It

#### A. As a Public Visitor / Prospect
1. Go to http://localhost:5173/
2. Scroll to the Contact / Request Demo form.
3. Fill in your details (e.g. Name, Email, Phone, Budget, Message) and click Submit Request.
4. The lead is saved directly to your MongoDB database.

#### B. As an Admin / Sales Representative
1. Go to http://localhost:5173/login (or click Live Admin Demo on the home page).
2. Log in with your admin credentials or register a new admin account.
3. Once logged in, you will be redirected to the Admin Dashboard (/admin):
- Kanban View: Switch columns or change statuses (New ➔ Contacted ➔ Qualified).
- Table View: Search by name/company and filter by priority (Urgent, High, Medium, Low).
- Add Internal Notes: Click on any lead to open the drawer/modal and write follow-up notes.
- Export Data: Click Export CSV to download all records.

---

5. How to Share This Project With Other Users

#### Option A: Quick Sharing on Your Local Wi-Fi / LAN
To let someone on the same Wi-Fi network test it on their phone or laptop:
1. In the client terminal, run:

   npm run dev -- --host

2. Vite will display a network URL (e.g. http://192.168.1.X:5173). Anyone connected to your Wi-Fi can open that URL.

#### Option B: Deploying to the Public Web (Free Cloud Hosting)
To give anyone in the world a live public link (https://your-leaddesk.vercel.app):
1. Frontend (Vercel or Netlify):
- Push your code to GitHub.
- Connect the client folder to Vercel or Netlify (100% free).
2. Backend (Render or Railway):
- Deploy the server folder to Render.com or Railway.app.
- Add your MONGODB_URI and JWT_SECRET in the Environment Variables tab.
3. MongoDB Atlas IP Access:
- In MongoDB Atlas ➔ Network Access ➔ click Add IP Address ➔ select Allow Access from Anywhere (0.0.0.0/0) so cloud servers can connect.

Step 2: How to Put It on the Internet (Free Public Website Name)

To get a live web address (like https://myleaddesk.vercel.app) that anyone can open on any phone, tablet, or browser anywhere in the world:

#### 1. Push your project to GitHub
1. Create a free account at github.com.
2. Create a new repository named leaddesk-mini.
3. In your terminal, run:

   git add .
   git commit -m "Deploy LeadDesk"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/leaddesk-mini.git
   git push -u origin main

#### 2. Deploy the Backend (Render.com - Free)
1. Go to render.com and click Sign Up.
2. Click New + ➔ Web Service and connect your GitHub repo.
3. Set:
- Root Directory: server
- Build Command: npm install
- Start Command: npm start
4. Under Environment Variables, add:
- PORT: 5000
- MONGODB_URI: mongodb+srv://jyotikumariroy204_db_user:YnrF335s3zvvYHlz@cluster0.dzrc2es.mongodb.net/leaddesk?retryWrites=true&w=majority&appName=Cluster0
- JWT_SECRET: mysecretkey123
5. Click Create Web Service. Render will give you a backend URL (e.g., https://leaddesk-api.onrender.com).

#### 3. Deploy the Frontend (Vercel.com - Free)
1. Go to vercel.com and sign in with GitHub.
2. Click Add New Project and select leaddesk-mini.
3. Set Root Directory to client.
4. Under Environment Variables, add:
- VITE_API_BASE_URL: https://leaddesk-api.onrender.com/api (your backend URL from step 2).
5. Click Deploy.

🎉 Vercel will instantly generate a live link for you, such as:
👉 https://leaddesk-jyoti.vercel.app

Step 3: How to Use Your Own Custom Domain (e.g. www.mycompany.com)

If you want a professional custom address (e.g., www.yourbrand.com):

1. Buy a domain from Namecheap, GoDaddy, Hostinger, or Google Domains.
2. Open your project on Vercel ➔ Go to Settings ➔ Domains.
3. Type your custom domain name (e.g., www.mybrand.com) and click Add.
4. Add the DNS records (CNAME) provided by Vercel into your domain provider dashboard.

3. What You Need to Do in MongoDB Atlas (Important Step)

To make sure your deployed cloud app can talk to MongoDB Atlas without errors, you only need to verify one setting:

#### Step: Enable "Allow Access From Anywhere" (0.0.0.0/0)
1. Log in to cloud.mongodb.com.
2. In the left sidebar, click on Network Access (under the Security section).
3. Check the IP Access List:
- If you see 0.0.0.0/0 (Status: Active), you are already set! 👍
- If not, click the green button + Add IP Address.
- Click Allow Access from Anywhere (this sets 0.0.0.0/0).
- Click Confirm.

> Why is this needed? Cloud hosting platforms like Render and Vercel use dynamic IP addresses. Adding 0.0.0.0/0 ensures your cloud backend can always connect securely with your database username and password.
